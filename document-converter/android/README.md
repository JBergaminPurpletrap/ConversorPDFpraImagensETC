# Document Converter Android

Aplicativo Android MVP do Document Converter.

## Escopo do MVP

Inclui:

- Imagem para PDF.
- PDF para Imagem.
- Tela Sobre.

Nao inclui inicialmente:

- DOCX para PDF.
- PDF para DOCX.
- PDF protegido por senha.

cd "C:\Projetinhos\Projeto conversor pdf\document-converter\android"
