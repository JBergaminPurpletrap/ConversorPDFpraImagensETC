# Politica de Privacidade - Document Converter

Ultima atualizacao: 2026-06-13

## Resumo

O Document Converter processa arquivos localmente no dispositivo do usuario.

Nenhum arquivo e enviado para servidores.
Nenhuma conta e necessaria.
Nenhum dado pessoal e coletado pelo aplicativo.

## Dados coletados

O aplicativo nao coleta dados pessoais.

## Processamento de arquivos

As conversoes sao executadas no proprio dispositivo Android:

- Imagem para PDF
- PDF para Imagem

Os arquivos selecionados pelo usuario sao acessados por meio do Storage Access Framework do Android.

## Internet

O aplicativo nao depende de internet para converter arquivos.

## Compartilhamento

Quando o usuario escolhe compartilhar um arquivo, o Android abre a tela nativa de compartilhamento. O destino escolhido pelo usuario passa a receber acesso temporario ao arquivo compartilhado.

## Logs locais

O aplicativo pode registrar logs tecnicos simples no armazenamento interno do proprio app, como:

- Conversao iniciada
- Conversao concluida
- Erros
- Tempo de execucao

Esses logs ficam no dispositivo e nao sao enviados automaticamente para nenhum servidor.

## Contato

Para duvidas sobre privacidade, entre em contato com o responsavel pela distribuicao do aplicativo.
